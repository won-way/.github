### 금융 문의를 이해하고, 정책에 근거해 가장 적절한 상담 경로를 안내합니다.

사용자의 자연어 문의를 분석한 뒤  
정책 데이터와 고객 상황을 검증하여 상담 채널과 업무 경로를 추천하는  
**AI 금융 상담 서비스**입니다.
